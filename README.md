**NeuroCAS-GNN**

**Project Overview**

This repository presents the implementation of a graph neural network-based framework for Autism Spectrum Disorder (ASD) classification using the ABIDE-I neuroimaging dataset.

**Dataset**

Dataset: ABIDE-I

Source: NITRC

Neuroimaging modality: rs-fMRI

Brain parcellation: Yeo-based representation

Implementation Environment

Google Colab

Python

Deep Learning and Graph Neural Network libraries

**Implementation Workflow**

ABIDE-I dataset preparation

Neuroimaging data preprocessing

Brain-region feature extraction

Functional connectivity representation

Brain graph construction

Graph neural network implementation

Model training and validation

ASD classification and performance evaluation


**Experimental Results
**
Final performance metrics will be reported based on the completed evaluation protocol, including accuracy, precision, recall, F1-score, and ROC-AUC.
